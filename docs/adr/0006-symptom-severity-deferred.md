# ADR 0006 — Symptom severity is deferred until post-launch feedback

The MVP records common symptoms as fast selectable Encounter-level observations.

The initial goal is rapid documentation during a short clinic workflow. Adding a severity level to every symptom increases interaction cost before there is evidence that the additional structure improves care or review efficiency.

Therefore MVP records symptom presence/absence plus optional Other text, but not structured severity.

No significant discomfort is mutually exclusive with all other symptoms.

After real clinic use, feedback should determine whether severity is useful enough to add and whether it should be:
- per symptom;
- one overall Encounter severity;
- limited to selected symptoms;
- or remain free-text only.

This is an intentional deferred decision, not an omitted requirement.
